球队名片 — 三种实现方案

核心链路：分享名片 → 外人扫码/点击 → 直接申请加入

A

海报图片 + 小程序码 ⭐ 推荐

后端调用微信 API 生成小程序码，嵌入精美海报图片。用户保存海报分享到朋友圈/群，外人扫小程序码直接跳申请页。

流程
队长生成 → 保存图片 → 发朋友圈/群 → 扫码 → 申请

优势

  • 可发朋友圈，传播范围最广
  • 扫码直达，体验流畅
  • 海报有设计感，代表球队形象

代价

  • 需调用微信 wxacode API
  • 后端需生成图片（Canvas 或模板）
B

小程序卡片分享

通过 wx.shareAppMessage 分享为微信消息卡片（带封面图和标题）。点击卡片直接跳申请页，实现最简单。

流程
点击分享 → 选联系人/群 → 对方点卡片 → 申请

优势

  • 开发最简单，改动最少
  • 无需生成图片

代价

  • 只能发到聊天，不能发朋友圈
  • 传播范围受限，不能截图再传
C

海报图片 + 邀请码文字

复用现有邀请码机制，在海报上印上邀请码。外人看到后手动到小程序输入邀请码加入。

流程
生成海报 → 分享 → 对方打开小程序 → 手动输入邀请码 → 申请

优势

  • 后端几乎零改动
  • 邀请码已有现成逻辑

代价

  • 需手动输入邀请码，转化率最低
  • 用户体验差
