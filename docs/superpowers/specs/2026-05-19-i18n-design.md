# 国际化（中英文切换）Design Spec

## 概述

为微信小程序添加中英文切换功能。仅翻译 UI 静态文字，用户输入内容（活动标题、地点等）保持原文。语言设置持久化，默认跟随微信系统语言。

---

## 架构

```
frontend/src/
├── i18n/
│   ├── zh.ts       # 中文翻译字典（主字典，定义全量键）
│   ├── en.ts       # 英文翻译字典（与 zh.ts 键一一对应）
│   └── useT.ts     # useT() hook
└── store/
    └── lang.ts     # 语言状态管理
```

### lang.ts（新建）

```ts
interface LangState {
  language: 'zh' | 'en'
  setLanguage: (lang: 'zh' | 'en') => void
}
```

- 初始值：读取 `wx.getStorageSync('language')`；若无，读 `Taro.getSystemInfoSync().language`（以 `zh` 开头则 `'zh'`，否则 `'en'`）
- `setLanguage` 写 Zustand 状态并同步 `wx.setStorageSync('language', lang)`

### useT.ts

```ts
// 返回翻译函数；key 不存在时返回 key 本身（不崩溃）
export function useT(): (key: string) => string
```

内部：`const { language } = useLangStore(); const dict = language === 'zh' ? zh : en; return (key) => dict[key] ?? key`

## 语言切换 UI（「我的」页面）

在「退出当前球队」按钮之前，新增一个与球队列表风格一致的列表行：

```
[ 语言 / Language ]     [ 中文 > ]
```

点击调用 `Taro.showActionSheet`：
```
选择语言 / Select Language
  ✓ 中文
    English
```

选中后调用 `setLanguage()`，Zustand 订阅触发，所有页面立即重渲染为新语言。

---

## 约束与已知行为

- 不翻译：用户输入内容（活动标题、地点、球队名等）
- 不翻译：后端返回的错误消息（保持中文）
- **导航栏标题**：各页面在 `useEffect` / `useDidShow` 中调用 `Taro.setNavigationBarTitle({ title: t('...') })` 动态设置；切换语言后重新进入页面时生效，当前页面立即生效（「我的」页在 `setLanguage` 后同步调用一次 `setNavigationBarTitle`）
- **Tab Bar 标签**：自定义 Tab Bar 为 Class 组件（WeChat 原生限制），在用户切换标签页时自动读取最新语言并重渲染；切换语言后立即在 Tab Bar 上生效需等用户触发一次 Tab 切换，属可接受行为
